# GraphDTA — Drug-Target Binding Affinity Predictor

GIN-based graph neural network for the drug + CNN with cross-attention for the
protein. Predicts binding affinity and highlights which residues the model
attended to.

Trained on Davis and KIBA. Weights loaded from
[Abdulrhman2002/graphdta-checkpoints](https://huggingface.co/Abdulrhman2002/graphdta-checkpoints).
